# sp-ime-dict

『SHINE POST（シャインポスト）』関連用語の IME 辞書です。キャラクター名、グループ名、曲名などを、各種 IME で快適に入力できるようにします。

**本プロジェクトは有志による非公式のものです。** 権利者および関連団体とは一切関係ありません。

このリポジトリには生成済みの辞書ファイルだけを置いています。辞書の元データと生成プログラムは公開していません。

## 辞書の種類

日常の日本語入力を壊さないよう、収録範囲の異なる 3 種類を配布します。

| 種類 | 内容 | おすすめ |
|---|---|---|
| `core` | フルネーム・正式名称など、一般語と衝突しない語のみ | **まずはこれ** |
| `extended` | `core` に略称・愛称を追加 | ファン向け |
| `full` | 一般語と衝突しうる語も含めて全部 | 専用プロファイルで使う人向け |

`extended` / `full` には「はる」「きょうか」のような一般語と同じよみが含まれます。普段の入力に影響が出ることを理解したうえでお使いください。

## ファイル

| IME | ファイル | 文字コード / 改行 |
|---|---|---|
| SKK | `skk/SKK-JISYO.shinepost.<tier>` | UTF-8 / LF |
| SKK（EUC-JP 版） | `skk/SKK-JISYO.shinepost.<tier>.euc` | EUC-JP / LF |
| Google 日本語入力 / Mozc | `mozc/shinepost.<tier>.txt` | UTF-8 / LF |
| Microsoft IME | `msime/shinepost.<tier>.txt` | UTF-16 LE（BOM 付き）/ CRLF |
| ATOK | `atok/shinepost.<tier>.txt` | Shift_JIS / CRLF |
| macOS ユーザ辞書 | `macos/shinepost.<tier>.plist` | plist |

`<tier>` は `core` / `extended` / `full` のいずれかです。件数と生成日時は `BUILD.txt` にあります。

ATOK と macOS は実機での取り込み確認が十分ではありません。取り込めない場合は Issue でお知らせください。

## 入手方法

- **固定 URL**: このリポジトリの GitHub Pages から直接取得できます。例: `https://tatsutarou-hyd.github.io/sp-ime-dict/skk/SKK-JISYO.shinepost.core`
- **zip**: [Releases](../../releases) から一式をダウンロードできます

## 誤変換・追加の要望

[Issues](../../issues) でお知らせください。誤変換の報告は「入力したよみ」「出てきた候補」「使用 IME」「辞書の種類」を添えていただけると助かります。

収録データは公式サイト・ゲーム内表記・公式資料などの一次情報から収集しており、他の辞書や wiki からの転記は行っていません。追加要望の際も一次情報の所在を添えていただけると助かります。
